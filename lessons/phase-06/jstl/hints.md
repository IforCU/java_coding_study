# Phase 6 단계별 힌트

먼저 [과제](exercise.md)의 데이터 키와 EL 속성 이름을 대조하세요. request attribute는 URL 파라미터와 다릅니다. 첫 렌더링에 성공한 뒤 반복, 조건, 빈 목록, 특수문자를 차례로 구현하세요.

먼저 api.success로 분기하고 성공한 경우에만 목록의 empty를 검사합니다. 실패와 성공·빈 목록은 서로 다릅니다. JSP에서 JSON을 파싱하거나 인증정보를 가진 HTTP 호출을 작성하지 않습니다. 실제 Boot API의 네트워크·HTTP·인증 계약은 본편 검증에서 따로 확인합니다.

화면의 건수는 표시 조건을 통과한 목록을 기준으로 합니다. 원화는 이미 BigDecimal로 준비되므로 JSP에서 반올림이나 거래 계산을 하지 않습니다. 주석을 처리해도 주변에 남은 구분 문자나 닫는 태그까지 자동으로 없어지지는 않습니다.

먼저 기본 smoke 검사를 통과하고, TODO 완성은 `jstl-check` 계약으로 확인하세요. 완성 코드와 해설은 정답 디렉터리에만 있습니다.
