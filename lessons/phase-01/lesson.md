# Phase 1 — Java 객체로 은행 업무 표현하기

이번 단계에서는 DB 없이 고객과 계좌를 메모리에 저장하는 Java 프로그램을 읽고 실행합니다. 정상 기준 구현은 `modules/01-java-core`입니다. 직접 작성할 TODO는 별도 실습 모듈에 있어 기본 실행과 섞이지 않습니다.

학습 목표는 다음과 같습니다.

- 클래스가 가진 상태를 캡슐화하고 메서드로 업무 규칙을 지키기
- 도메인 객체와 외부에 전달하는 DTO를 구분하기
- 인터페이스로 저장 방식과 업무 흐름을 분리하기
- `BigDecimal`로 원 단위 금액을 정확하게 비교하고 계산하기
- 예외가 발생한 거래에서 잔액과 거래 내역이 함께 보존되는지 검증하기
- Collections로 고객의 여러 계좌와 계좌별 거래 내역을 관리하기

## 정상 예제로 관찰할 업무

`BankDemo`는 학습 고객을 만들고 계좌 두 개를 개설합니다. 첫 계좌에 100,000원을 입금한 뒤 35,000원을 출금하고, 둘째 계좌에는 5,000원을 입금합니다. 실행이 끝나면 잔액과 거래 내역을 출력합니다. 현재 저장소는 메모리이므로 프로그램을 종료하면 데이터도 사라집니다.

정상 기준 실행 방법과 결과는 [verification.md](verification.md)를 확인합니다. 이 단계는 HTTP, Servlet, SQL 없이 Java 업무 규칙에 집중합니다.

## 클래스와 책임

`BankService`는 고객 조회, 계좌 개설, 입출금과 결과 DTO 생성을 연결합니다. `domain.Account`는 잔액과 거래 내역을 가진 업무 객체입니다. 호출자가 필드를 직접 변경하지 않고 입금·출금 메서드를 거치게 하면 금액 검증과 기록 생성을 한곳에서 지킬 수 있습니다.

`BankRepository`는 저장 기능의 인터페이스이고 `InMemoryBankRepository`는 메모리 구현입니다. 업무 서비스가 구체적인 `Map` 저장 방식을 직접 다루지 않도록 하는 경계입니다. 이후 JDBC 구현이 추가되어도 업무 규칙을 어느 계층에 남겨야 할지 비교할 수 있습니다.

`dto.CustomerView`, `dto.AccountView`, `dto.TransactionView`는 조회 결과를 전달하는 Java 17 record입니다. 내부 계좌 객체를 그대로 돌려주지 않고 값의 스냅샷을 전달합니다. record는 멤버 참조를 다시 대입하지 못하게 하지만, 가변 컬렉션을 넣는다면 별도의 방어가 필요합니다. 이 모듈은 반환 리스트도 외부에서 수정할 수 없도록 합니다.

## 금액과 예외

학습 범위의 통화는 원화이며 금액 단위는 1원입니다. 입출금액은 양수만 허용하고 원 미만 값은 반올림하지 않고 거절합니다. `100.00`은 수치상 정수이므로 100원으로 받아들이지만 `100.1`은 거절합니다. 금액 생성과 비교에 대한 설명은 [금액 처리 문서](../../docs/banking-domain/money.md)에 있습니다.

잔액 부족, 잘못된 금액, 존재하지 않는 고객·계좌는 서로 다른 업무 오류입니다. 실패 시 금액만 확인하지 말고 거래 내역도 늘어나지 않았는지 확인합니다. 화면이나 API를 붙이기 전에 도메인 테스트로 규칙을 고정하면 외부 표현이 바뀌어도 업무 의미를 유지하기 쉽습니다.

## 시간과 재현 가능한 테스트

거래 시각을 매번 시스템 시각에서 직접 읽으면 정확한 결과를 단정하기 어렵습니다. `BankService`가 `Clock`을 받게 구성하여 테스트에서 고정 시각을 전달할 수 있습니다. Java 공식 문서도 테스트를 단순하게 만드는 용도로 대체 Clock을 설명합니다. [Java 17 Clock](https://docs.oracle.com/en/java/javase/17/docs/api/java.base/java/time/Clock.html)

코드를 읽은 뒤 [exercise.md](exercise.md)의 출금 가능 정책을 직접 구현합니다. 기준 프로젝트와 실습은 서로 다른 모듈입니다.

Java 과제를 마친 뒤 화면도 직접 작성하려면 [은행 JSP/JSTL 실습](../phase-02/jstl/lesson.md)으로 이어갈 수 있습니다. DB 없이 계좌 목록과 금액·상태를 표시하는 화면을 연습합니다.
