# 단계별 힌트

막힌 부분만 순서대로 확인하세요. 완성된 JSP 해설은 별도 정답 디렉터리에 있습니다.

## 인사와 안전한 출력

`param`은 URL 파라미터, `accounts`는 Servlet이 전달한 request attribute입니다. 앞뒤 공백을 제거한 후 `empty`로 검사하세요. EL로 읽은 문자열이 자동으로 HTML 이스케이프되는 것은 아닙니다. 텍스트뿐 아니라 input의 value와 링크 href에 넣는 값도 확인하세요.

## 반복과 건수

먼저 전체 목록을 반복한 뒤 종류 필터를 추가하세요. 표시 건수를 증가시키는 위치는 필터를 통과한 블록 내부입니다. 전체 반복의 `varStatus.index`는 필터 후 표시 순번과 다를 수 있습니다. 특히 적금만 선택해 보세요.

JSTL의 page scope 변수는 같은 요청의 JSP 처리 중 유지됩니다. 결과 건수는 반복문보다 앞에서 초기화하고 반복 후에 검사하세요. 전체 건수와 표시 건수는 서로 다른 값입니다.

## 분기와 금액

상태 코드와 한글 표시를 분리하고 `c:choose` 안에 `c:when`, `c:otherwise`를 배치하세요. '0원'은 비어 있는 값이 아닙니다. 금액 표시에는 로케일과 숫자 형식을 명시하세요. 이번 데이터는 이미 원 단위 정수이므로 화면에서 계산할 필요가 없습니다.

## 오류를 볼 때

JSP 주석은 `<%-- ... --%>`입니다. HTML 주석 안에 태그를 적으면 JSP 엔진이 처리할 수 있으므로 TODO를 숨기는 용도로 혼동하지 마세요. 태그의 열고 닫힘, EL의 중괄호, 속성 따옴표를 확인합니다. Tomcat 9의 javax JAR를 추가해 해결하려 하지 마세요.

화면이 200을 반환하는 것과 과제 계약을 만족하는 것은 다릅니다. 먼저 기본 smoke 테스트로 컴파일을 확인하고, `jstl-check`로 동작을 검증하세요.
