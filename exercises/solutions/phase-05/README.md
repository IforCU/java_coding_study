# Phase 5 마스킹 정답과 해설

아래 Maven 명령은 프로젝트 루트에서 실행합니다.

정답 모듈은 기본 애플리케이션과 분리되어 있습니다. 과제를 시도한 뒤 비교합니다. 장애 여덟 종류의 별도 해설은 [incident-solutions.md](incident-solutions.md)에 있습니다.

정답은 null을 거절한 뒤 허용 구분자인 ASCII 공백과 하이픈만 제거합니다. 나머지가 ASCII 숫자 8~20자리인지 확인하고, 마지막 네 자리를 제외한 각 자리를 `*`로 바꿉니다. `[0-9]`를 명시하여 Unicode 숫자나 보이지 않는 공백을 허용하지 않습니다. 허용하지 않은 구분자를 지우고 통과시키는 방식으로 검증을 느슨하게 하지 않습니다.

결과 길이는 정규화한 길이와 같습니다. 앞자리 0도 숫자 문자열의 일부이므로 정수 타입으로 바꾸지 않습니다. 잘못된 입력을 예외 메시지에 포함하지 않아 오류 경로에서도 원문을 반환하지 않습니다. 입력 String은 불변이고 함수는 별도 상태를 저장하지 않습니다.

마스킹은 화면과 로그에 표시할 범위를 줄이는 정책입니다. 암호화, 인증·인가, 원본 데이터 보관 정책을 대신하지 않습니다. 값을 마스킹했더라도 SQL 값 바인딩과 출력 문맥의 이스케이프는 각각 유지합니다.

```sh
mvn -Dmaven.repo.local=.cache/maven-repository -Psolution-phase5 -pl exercises/solutions/phase-05 -am verify
```

정답은 starter의 같은 계약 테스트를 사용합니다. 테스트 결과는 루트 `PROGRESS.md`에서 확인하며, 실제 웹·DB 검증과 분리해 기록합니다.
